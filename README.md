# Socket chat client example

An early Vue chat client experiment.

> **Status:** Archived historical example; no active maintenance is planned.

## Local commands

These commands reflect the repository scripts. This historical project has not been validated against current runtimes.

```sh
npm install
npm run serve
npm run build
```
The corresponding server experiment is [`socket-chat-server-html`](https://github.com/erolsenol/socket-chat-server-html).
